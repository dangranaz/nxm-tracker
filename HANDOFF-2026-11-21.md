## Cosa è stato completato (fino a v0.7.1)

### Session model (v0.6.0)
- `Session` con `id`, `name`, `started_at`, `ended_at`, `status`, `design_phase_complete`
- `SessionStatus` enum: `Open`, `Paused`, `Closed` (serializzato come stringhe minuscole nel DB)
- `FeatureSession` per integrated feature session post-design phase
- `SessionRepository` trait + `SqliteSessionRepository` implementazione su pool `nxm-db`
- Migration v1: `create_sessions`, Migration v2: `create_feature_sessions` (con FK)
- `TrackerError::InvalidSessionStatus` per status string non riconosciute
- 11 test di integrazione in `tests/session_test.rs`

- Dipendenze aggiunte: `nxm-mcp-server`, `serde_json`
- 11 test di integrazione in `tests/mcp_tools_test.rs`
